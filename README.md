## Overview

A data-driven **observability and performance monitoring platform** built to visualize study abroad participation and program trends across **300+ global institutions**.

The platform provides centralized dashboards for analyzing participation across terms, countries, majors, schools, gender, and ethnicity, enabling leadership teams to monitor program performance and make data-driven decisions.

## Key Capabilities

- **Performance Monitoring:** Track study abroad participation and program trends across **300+ institutions**.

- **Data Visualization:** Interactive dashboards with filters for term, academic year, country, major, and school.

- **Data Processing:** Preprocessed and analyzed datasets using **Python, Pandas, and SQL**.

- **Web Integration:** Embedded Tableau dashboards into a **React** application for a unified user experience.

- **Data Export:** Provided presentation-ready and exportable views for leadership reporting.

- **Operational Enablement:** Trained staff to update data sources, use filters, and maintain dashboards.
